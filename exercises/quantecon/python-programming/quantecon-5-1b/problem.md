# Count Even Numbers (QuantEcon 5.7.1, Part 2)

In one line, count the number of even numbers in $0, 1, \dots, 99$.

Define a function `count_evens()` (no arguments) that returns this count. The body should be a single expression — e.g. a `sum(...)` or `len(...)` over a comprehension.

Hint: `x % 2` returns 0 if `x` is even, 1 otherwise.
