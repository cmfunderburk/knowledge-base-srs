# Count Even Pairs (QuantEcon 5.7.1, Part 3)

Given a sequence of `(a, b)` pairs, count the number of pairs such that both `a` and `b` are even.

Define a function `count_even_pairs(pairs)` that takes any iterable of two-element pairs and returns the count.

Example: for `pairs = ((2, 5), (4, 2), (9, 8), (12, 10))`, the answer is `2` — only `(4, 2)` and `(12, 10)` have both even.
